# Smart Campus Platform

A web-based platform designed to help manage common college activities in one place.

## Features

- Student and Admin login
- Student registration
- Task management
- College announcements
- Event publishing
- Complaint submission and status tracking
- Role-based access

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git and GitHub

## Run Locally

1. Clone the repository.
2. Open the project folder.
3. Create and activate a Python virtual environment.
4. Install Flask:

   pip install flask
